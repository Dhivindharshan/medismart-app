# MediSmart — Android app downloads

Signed release builds of the MediSmart Android app. This repository holds release files only; the app's source code is private.

**Download page:** https://medismart-smart-medication-system.vercel.app/download
**Website:** https://medismart-smart-medication-system.vercel.app/

Each release lists the version, file size, minimum Android version and the APK's SHA-256 checksum.
All releases are signed with the same MediSmart key (certificate SHA-256
`2bf0d2739c194ba2dd990e60a2ecc3d9f06e7e71aed34a17b494035e369a5c5f`), so a newer APK installs over an older one.
